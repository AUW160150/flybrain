MaleCNS atlas: the exact graph behind the experiment

Before trusting a null result you should be able to see the graph it was computed on. This project is a read-only inspection layer over the language experiment: it verifies that the saved 512-neuron graph is what the published connectome says it is, and lets you look at it from every angle without touching the experiment's files.

What it verifies

  • Identity. The graph hash 354ccf91…534b matches the saved parent arrays and the matching published bulk product. Exact model-index and parameter-index CSV exports; zero structural weights remain among the allowed edges.
  • Scope. The 512 neurons are one sampled neighbourhood. The whole release has 151,856,684 ordered pairs; the interface exposes separate blocked scopes (G0/G1/G2) with the exact command to populate each, rather than pretending whole-graph statistics exist.
  • Partners. Exact incoming and outgoing partner access for each selected neuron, including partners outside the subset, from a complete raw-file scan.
  • Architecture. Executed-source predictor diagrams, folded and unrolled, with the dense interfaces and 52,981 active parameters; untrained MLP, causal CNN and transformer references instantiated with shape and causal-prefix tests, no performance comparison.
  • Non-interference. The experiment's environment, graph, configurations, checkpoints and corpus are protected inputs. A separate virtualenv, read-only reuse of installed packages, CPU only, one thread, lower process priority, and a receipt proving nothing in the experiment changed.

What is deliberately blocked

Learned-weight and activity overlays are not shown. Eleven completed FLY-TOPOLOGY checkpoints were copied to content-addressed snapshots, but torch.load(weights_only=True) rejects their NumPy RNG pickle state, and no unsafe fallback or guessed initialisation was used. The report says exactly what a safe export would need. Whole-release ingestion (64 GiB of SQLite planning, 512 MiB RSS guard) is implemented and tested on fixtures but has not been run on the production tables.

Run it locally

cd projects/connectome-atlas
./viz inspect-workspace
./viz verify-run --run-dir ../connectome-lm/runs/<a completed run>
./viz ingest-subset --rss-mib 512 --max-seconds 120
./viz build-views && ./viz validate
./viz serve --host 127.0.0.1 --port 8765        # the interactive viewer
./viz export-neuron --scope G3 --id 10029

The static report hosted here is reports/current/index.html with its figures; the interactive viewer, geometry and exact matrices need the local build.
