Can the circuit learn without backpropagation?

Most artificial networks learn by backpropagation: an error signal is sent backwards through every connection to work out how each one should change. Brains almost certainly do not learn this way. This experiment planned to train the same fly steering circuit with forward-only rules, which jiggle the neurons a little, keep the changes that improve the result, and never send anything backwards, and then to compare those rules fairly. A small pilot came first, to measure how much results vary from one random starting point to the next. They varied far too much, and the experiment stopped itself, as its own rules required.

The question

The circuit is the same 443-neuron steering circuit as in project 08, driving the same simulated robot. Forward-only learning was tried in two modes. In the first, the robot learns by copying recorded demonstrations from a teacher. In the second, it learns from its own driving, scored by a reward. The main study would have made 260 training runs, plus 182 short runs to tune learning rates, and compared forward-only rules with each other and with backpropagation.

A comparison like that is only worth running if results are steady enough between training runs that a real difference can stand out. The plan's run counts assumed a run-to-run variability of 0.03 on the main score, a figure carried over from runs trained with backpropagation. Forward-only training is noisier by design, so the pilot measured it directly first, with a rule fixed in advance: below 0.025, go ahead as planned; from 0.025 up to 0.045, recompute how many runs are needed; at 0.045 or above, stop.

Why it stopped

What the numbers mean

“Variability” here is the typical amount by which one random start's result differs from another's, measured on the gap between the two training modes. The line in the lower panel is the planned study's chance of giving a clear answer, worked out before the pilot for a range of variabilities: 89% at the planned 0.03, falling to 16% at 0.10. The measured value, 0.1348, is beyond the last point that was worked out, so no chance is drawn for it; it can only be lower.

Collisions told the same story: their variability came out at 0.0598, also above the stop line. In all five starts, learning from its own driving ended with a lower main score than copying the teacher. With five starts that is a description, not a test.

Gap between the two modes on the main score, per random start, each scored on the same 2,000 fresh scenes: −0.7, −8.7, −15.6, −29.4 and −32.4 points. Variability is the standard deviation of these gaps, corrected for the scene-to-scene noise they share.

What this does not show

  • It does not show that forward-only learning cannot train this circuit. Every pilot run finished its 4,000 updates and none failed; the problem is how much the results differ between runs.
  • It does not say which training rule is better. That comparison is the main study, and it was never run.
  • Five pairs of runs give only a rough estimate of variability. The estimate would have to be very far off, though, to fall back under the stop line.
  • The pilot used one version of the circuit and one learning setting. Other settings might be steadier; that was not tested.

How it was run

The stopping rule, the run counts it would govern and the pilot's own settings were fixed and fingerprinted before any pilot run, and the pilot's scenes were fresh. The rule was applied automatically when the last run finished, and it was not adjusted afterwards. The pilot runs are excluded from any later study.
