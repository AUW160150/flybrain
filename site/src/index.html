Seven experiments · one connectome · 2026

The fly's wiring diagram, put to work.

Flybrain is a set of experiments built on MaleCNS v1.0, the synapse-level map of a male fruit fly's central nervous system. Some turn the wiring into things you can play: an arena where small flies run on real sub-circuits, a browser studio, a garden seen through a fly's eyes. Others ask hard questions of it and report the answers as measured, including the null results.

Results

08 — 10 · measured, mostly negative

How the work was done

protocols · ledgers · gates

Each project started with a written protocol and ended with a status ledger. Learning experiments were preregistered in the local sense: an analysis plan hashed before training, development selection on validation data only, a frozen configuration, and a single explicit command that opened the test split. Where a comparison came out flat, the page says so.

The three latest experiments (08 to 10) went further: each was preregistered with its analysis code frozen and fingerprinted, and with gates decided in advance, the results that would count as a win, as ruling an effect out, or as a reason to stop. Two of them ended at such a gate. That discipline, more than any single number, is what this work establishes.

Every number on these pages is copied from a saved artifact in the repository: a run manifest, an audit JSON, a figure's sidecar. Nothing is re-derived for the website. The boundaries are stated too: synapse counts are structural weights, not physiological ones; the arena flies are artificial models constrained by real wiring, not emulated animals; the first-person garden is sampled through a female reference eye that has not been registered to the male connectome.

One dataset, one specimen

All seven projects read the same three files from the MaleCNS v1.0 release: body annotations, body neurotransmitter predictions and the traced-to-traced connection table at confidence ≥ 0.5. The release is pinned by file hash in every project's manifest. The browser demos on this site carry bounded, pre-extracted subsets; the raw tables (about 1.1 GB) stay on the machine that built them.
