# Limits of this delivered snapshot

- G0/G1/G2 production disk indexes, whole-release matrices and full quotient diagrams are not built. Source files are present and verified. Full ingestion is implemented and fixture tested, with exact bounded commands in README. The viewer exposes blocked panels instead of a substituted graph.
- G1 selected-incidence access covers only neighborhoods of the exact saved IDs. It supports every partner for those nodes, including low-contact and outside-subset pairs, but is not a whole-neuron graph. Outside-neuron full neighborhoods require the full index.
- Geometry is partial: 8 exact saved IDs, no context mesh, no whole-CNS scene locally. Missing neurons remain present in all graph counts. SWC coordinates were checked against catalogue units/bounds, not independently registered against a second anatomical measurement.
- No trained weights, trained activations, initial-weight comparison or attention-coefficient heatmap is enabled. Tensor-only checkpoint loading failed; unsafe pickle loading was never attempted. No guessed-seed initialization is treated as saved evidence.
- Live browser testing/screen captures are skipped: loopback bind was denied, and standalone Chrome aborted with exit 134. Backend/HTTP-route and numerical tests passed. DOM layout, bookmarks and actual browser interactions require the included CDP harness outside this sandbox. Figure PNGs are Pillow companions, not browser screenshots.
- Current available RAM and process listing were inaccessible. We treated documented confirmation training as active throughout. Bounded CPU work ran with one thread and lower priority. No source process was stopped, restarted or controlled. Protected static hashes remain unchanged; active writer-owned run files were free to progress.
- No release was silently substituted, no sampling performed, no synthetic fixture appears in the authentic report, and no sealed test loader was invoked.
- The scope definitions represent a released minconf-0.5 product and an explicit Traced inventory rule. They do not establish complete biological knowledge or absence of every biological connection. Contact counts are not physiological weights; model states are not firing measurements.
- The sample is a local shuffled-BFS neighborhood from one specimen, not proportionate coverage of all regions. Its source annotations contain 488 ol_intrinsic, 21 visual_projection, two visual_centrifugal and one descending_neuron entry. These are published labels, not a functional interpretation of text processing.
- There is no Git repository. Source archives, content digests and export sidecars provide revision evidence. Dependency versions are pinned to the installed package closure, without claiming a clean-machine reinstall was tested.
