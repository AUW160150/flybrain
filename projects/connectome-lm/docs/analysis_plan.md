## Question and outcome
At fixed training prediction-byte exposures, compare a from-scratch graph recurrent byte model constrained by MaleCNS to labelled directed degree-preserving nulls. Primary outcome is total test natural-log cross entropy / scored bytes / ln(2). Per training seed delta = mean rewired BPB minus the single fly BPB. Chosen practical threshold: +0.02 BPB. Bootstrap seed-level paired deltas 10,000 times for a 95% percentile interval; five seeds give limited uncertainty. Report all runs and failed seeds. Pilot is validation-only; smoke supports software checks only.
