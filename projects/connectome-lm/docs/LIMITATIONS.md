# Limitations and unexecuted work

- Smoke validates execution only. No claim that MaleCNS wiring helps next-byte prediction follows from it.
- This is a neuron-level local BFS sample from one male specimen, not the whole brain/CNS. Overlapping replication samples are not independent animals. Local BFS biases circuit selection; a random initialization seed does not remove anatomical sampling bias.
- `Traced` defines the operational curated inventory. Orphan/Assign/Anchor/Unimportant/missing-status entries are excluded and counted, not declared definitively non-neuronal. Missing type on a retained traced neuron is preserved.
- Randomization preserves labelled in/out degree, not strong connectivity or physiological function. Fixed accepted swaps do not prove uniform sampling or mixing. No null is selected by its language score.
- Learned signed recurrent weights, tanh states, one update per byte, leak, dense text interfaces and gradient descent are engineering choices. No physiological-time, membrane-voltage, biological-language or consciousness interpretation is justified.
- Shakespeare is a narrow public-domain benchmark. Exact shared spans >=256 bytes are audited, but shorter repeats and thematic/style overlap still limit generalization. Byte perplexity is not token/word perplexity.
- All required conditions and optional transformer/frozen/count modes are implemented. Only the bounded real-data smoke and tests are claimed executed unless STATUS explicitly adds a command. Development tuning, configuration freeze, confirmation, final-test, multi-graph replication and fixed-time research are unrun.
- Optional independent Alice corpus acquisition/retraining is deferred. The separately labelled 1024-node follow-up has extraction support only; existing research commands enforce 512 nodes.
- The initial process cannot use CUDA/MPS. Accelerator tests are skipped honestly; future use requires local forward/backward checks for the chosen common backend. CPU is tested. Hardware RAM/CPU-model sysctl was denied; no unverified hardware capacity is asserted.
- Existing workspace virtualenv was reused without mutation, and relevant installed dependencies are locked. Other OS/backend versions may need new verification. No Git repository exists; code hashes and a null Git revision are recorded instead of inventing a commit.
- Python child network access failed DNS in this sandbox; top-level curl could fetch public evidence and text. Existing dataset files were verified against catalogue-linked official object headers, including size/MD5, then SHA-256 hashed. Original cache acquisition times are unknown. A content hash alone is not evidence of provenance.
- CPU RSS is process-lifetime high-water, not isolated per-run memory; operation/storage estimates omit library overhead. Training/time protocols are separate. Actual pilot runtime, convergence and statistical power have not been established.
- Tests check specified invariants; they do not prove the whole pipeline correct. Full research-scale orchestration and all optional combinations remain unvalidated end to end. All future recipe changes must be separately labelled and made before test access.
