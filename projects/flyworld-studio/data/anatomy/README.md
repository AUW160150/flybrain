# Audit-only anatomy cache

`raw_refs/` contains byte-identical, content-addressed copies of eight canonical source SWCs and their acquisition receipts. Originals remain read-only in the parent visualization cache. The retrieval subdirectory contains the failed bounded request record, not a recovered requested-body skeleton.

`converted/` contains separate JSON derivatives preserving every numeric SWC column, header, root and parent relation. Scale is 1 and the stored transform is identity. Nothing is mirrored, healed, simplified or registered.

`manifests/` contains the protected-source baseline, authoritative body projection, mapping evidence, existing-derivative checks, conversion provenance and summary. These records distinguish body geometry verification from unverified anatomical orientation and mutation alignment.

These files are not exposed by the app's public data catalog. Use the audit scripts to reproduce them; immutable writes refuse changed bytes at an existing output path. Scientific findings and source links are in `docs/anatomy/` and `docs/CHECKPOINT_04A_ANATOMY_AUDIT.md`.
